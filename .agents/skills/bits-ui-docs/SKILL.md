# Bits UI documentation

Use Bits UI's LLM-friendly documentation instead of relying on memory. The
LLM-friendly pages contain the same Markdown exposed by the **Copy Markdown**
button and are designed for machine consumption.

## Find the right documentation

1. Start with the root index: <https://bits-ui.com/llms.txt>. It lists the
   documentation endpoints that support the LLM format.
2. For a specific documentation page, append `/llms.txt` to its normal URL.
   For example, use
   <https://bits-ui.com/docs/components/accordion/llms.txt> for Accordion.
3. Use the page-specific endpoint whenever possible. For broad research, use
   the consolidated documentation at <https://bits-ui.com/docs/llms.txt>.
4. Some pages do not support the `/llms.txt` suffix. Confirm availability in
   the root index before depending on an endpoint.

When reviewing Bits UI examples, ignore demo CSS class names unless styling is
relevant to the task.

Source: <https://www.bits-ui.com/docs/llms/llms.txt>
